# AI 优先的股票分析平台 - 设计文档体系

## 文档总览

本目录包含从 `ai-stock-analysis-platform-plan.md` 拆分并优化后的独立设计文档。每个文档聚焦一个子系统或设计维度，可独立阅读，也可组合参考。

| 编号 | 文档 | 覆盖范围 | 关键产出 |
|------|------|----------|----------|
| 01 | 产品概览与可行性分析 | 项目定义、目标用户、竞争分析、可行性评估 | 用户画像、竞品矩阵、切入点论证 |
| 02 | 系统架构设计 | 双项目架构、部署拓扑、数据流、渐进式策略 | 架构图、通信协议、扩容方案 |
| 03 | 富交互 Chat 前端设计 | 页面布局、容器体系、股票卡片、引导交互 | 组件规范、状态管理、SSE 协议 |
| 04 | 用户个性化功能设计 | 自选股、持仓、盯盘引擎、定时任务、通知中心 | 规则引擎、调度模型、推送链路 |
| 05 | 专业报告中心设计 | 报告资产化、分类体系、对比、导出 | 报告模板、检索索引、版本管理 |
| 06 | AI 对话中枢设计 | 意图路由、ChatMemory、Function Calling、RAG | Graph 编排、工具协议、幻觉防护 |
| 07 | 数据架构与数据库设计 | C 端业务表、Tushare 业务表、缓存策略 | ER 模型、索引策略、数据治理 |
| 08 | 技术选型与基础设施 | C 端 / B 端 / 计算服务技术栈、环境配置 | 选型依据、依赖矩阵、部署方案 |
| 09 | 开发路线图 | Phase 0-4 任务拆解、依赖关系、里程碑 | 任务清单、验收标准、依赖图 |
| 10 | 风险与质量保障 | 风险矩阵、假设与决策、验证体系 | 风险评级、测试策略、监控告警 |

## 阅读建议

- **产品经理 / 项目负责人**：从 01 开始顺序阅读，重点看 01、05、09
- **后端架构师**：从 02 开始，重点看 02、06、07、08
- **前端工程师**：重点看 03、04、05
- **数据工程师**：重点看 02、07、08
- **测试 / QA**：重点看 09、10

## 文档间关系

```
01 产品概览 ──────┐
                  ├─→ 09 开发路线图 ──→ 10 风险与质量保障
02 系统架构 ──────┤
                  │
03 前端设计 ──────┤
04 个性化功能 ────┼─→ 06 AI 对话中枢
05 报告中心 ──────┘
                  
07 数据架构 ──→ 08 技术选型
```

01-05 为产品设计层，定义"做什么"；06-08 为技术设计层，定义"怎么做"；09-10 为工程管理层，定义"何时做、如何保障"。
